# 🎲 Jogo do Número Secreto

Este é um projeto simples de um jogo interativo desenvolvido com HTML, CSS e JavaScript puro, onde o objetivo é adivinhar um número secreto gerado aleatoriamente pelo sistema.

🔗 **Acesse o jogo:**  
[👉 Clique aqui para jogar](https://marcelobueno25.github.io/game.numero.secreto/)

## 🚀 Funcionalidades

- Geração aleatória de um número secreto.
- Reconhecimento de comandos de voz para inserir palpites.
- Feedback visual e textual para palpites corretos, errados ou inválidos.
- Mensagens dinâmicas que guiam o jogador até acertar.
- Reinício do jogo sem recarregar a página.

---

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Web Speech API](https://developer.mozilla.org/pt-BR/docs/Web/API/Web_Speech_API) (Reconhecimento de voz)
